# Homebrew tap

Homebrew casks for [CoreRemote](https://github.com/meteciftci/core-remote).

```sh
brew install meteciftci/tap/coreremote
```

CoreRemote is ad-hoc signed and not notarized by Apple. The cask removes the quarantine flag after installing, so macOS opens it without the Gatekeeper warning. Only install it if you trust this tap.

The cask is updated automatically when a new CoreRemote version is released.
